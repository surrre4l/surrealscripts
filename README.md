
# surrealscripts.ui

A personal dashboard for managing Lua and Luau scripts.

## Features

- Browse and organize scripts
- Search scripts by name
- View script information
- Track source availability
- Display SHA-256 hashes for integrity verification
- Support AES encryption in a trusted environment

## Important

This project uses GitHub Pages for static hosting.

Do not store private scripts, secret encryption keys, or sensitive credentials in a public repository.

SHA-256 hashes help verify file integrity when compared against a trusted hash. AES encryption requires secure key management.

- HTML
- CSS
